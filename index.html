🌐 Opsi 1: Pasang di GitHub Pages / Buka di Browser

Ya! Aplikasi Ini 100% Siap Di-Upload ke GitHub Pages Anda (`index.html`)

Karena aplikasi ini dirancang dalam 1 file HTML mandiri (Single-File HTML), Anda punya 2 cara mudah untuk menggunakannya kapan saja:

Cara A: Upload ke GitHub Pages (Bisa Diakses Online Tim Teknis)

  1. Klik tombol "💾 DOWNLOAD FILE `index.html` SEKARANG" di atas.
  2. Buka akun GitHub Anda, buat repository baru (misal: ebmd-turbo) atau masukkan ke folder di repo Anda.
  3. Upload file index.html tersebut, lalu aktifkan menu Settings ➔ Pages ➔ Branch: main.
  4. Aplikasi siap dibuka dari komputer mana saja! Semua file Excel yang diupload hanya diproses di memori browser lokal sehingga aman & super cepat.

Cara B: Buka Langsung di Komputer Tanpa Internet/Hosting

  1. Setelah klik "💾 DOWNLOAD FILE `index.html`", simpan file tersebut di Desktop komputer Anda.
  2. Klik 2 kali (Double-Click) file index.html tersebut untuk membukanya langsung di Google Chrome.
  3. Atau Anda juga bisa langsung menggunakan tampilan Preview di sebelah kanan layar chat ini sekarang juga!
★ Opsi 2: Cara Paling Canggih & Permanen (Tanpa Bolak-Balik Tab & Tanpa F12)

Tanamkan Tombol "📂 Upload File Excel (.xlsx)" Langsung di Dalam Website E-BMD Donggala!

Jika Anda memasang Universal Super Script di bawah ini ke ekstensi Chrome Tampermonkey (cukup 1 kali pasang), maka setiap kali Anda membuka halaman Rincian E-BMD (`e-bmd.donggala.go.id`), di pojok kanan bawah layar E-BMD akan otomatis muncul kotak Upload File Excel (.xlsx). Anda tinggal pilih file Excel sekolah di situ dan klik Eksekusi!

Langkah 1: Pasang Tampermonkey (Sekali Saja)

Install ekstensi Tampermonkey dari Chrome Web Store, lalu klik ikon Tampermonkey di pojok kanan atas browser ➔ pilih "Create a new script..." (Buat skrip baru).

Langkah 2: Paste & Simpan (Ctrl + S)

Hapus semua isi awalnya, klik tombol "📋 COPY UNIVERSAL SUPER SCRIPT" di atas, lalu Paste (Ctrl+V) ke dalam Tampermonkey dan tekan Ctrl + S.

Langkah 3: Upload Excel Langsung di E-BMD!

Buka halaman Rincian E-BMD (`spkasettetap`), panel akan muncul otomatis selamanya. Anda tinggal klik "📂 Pilih File Excel (.xlsx)" di dalam layar E-BMD lalu klik Eksekusi!
